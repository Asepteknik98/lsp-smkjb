# 📖 Tentang Proyek

Website **LSP SMK Jaya Buana** merupakan platform digital resmi yang dikembangkan untuk menyediakan informasi, layanan, dan administrasi terkait kegiatan **Lembaga Sertifikasi Profesi (LSP)**.

Website ini hadir sebagai media informasi yang modern, profesional, dan mudah diakses oleh peserta, asesor, industri, maupun masyarakat umum.

Platform ini mendukung berbagai kegiatan, di antaranya:

- 📚 Informasi Sertifikasi Kompetensi
- 👨‍🏫 Pelatihan Asesor Kompetensi
- 📅 Jadwal Pelatihan dan Asesmen
- 📝 Informasi Skema Sertifikasi
- 📄 Dokumentasi Kegiatan
- 📢 Pengumuman Resmi
- 📞 Informasi Kontak

---

# 🎯 Visi

Menjadi lembaga sertifikasi profesi yang profesional, terpercaya, dan mampu menghasilkan sumber daya manusia yang kompeten sesuai Standar Kompetensi Kerja Nasional Indonesia (SKKNI).

# 🏆 Program Unggulan

## Pelatihan Asesor Kompetensi

Pelatihan Asesor merupakan salah satu program utama LSP SMK Jaya Buana yang bertujuan menghasilkan asesor kompetensi yang profesional sesuai standar BNSP.

Program ini membantu peserta memahami:

- Prinsip Asesmen
- Teknik Observasi
- Penyusunan Bukti Kompetensi
- Pengambilan Keputusan Asesmen
- Penyusunan Dokumen Asesmen
